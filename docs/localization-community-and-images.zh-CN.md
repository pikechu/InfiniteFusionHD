## 合入最新 main 后的发布范围

英文原文、署名及新增内容均保留。读取上限调整为 32 MiB，以支持当前约 19 MiB 的英文库；中文资料仍通过原文、精灵图及作者共同匹配。全量读取、中文排版与英文→中文→英文检查覆盖新版本；证据见 `2026-10-27-android14-integration/`。

## 图鉴内容与审校方法

- 中文资料位于 `Data/pokedex/dex_zh.json`，每条保留原作者、精灵图路径和完整英文原文。按完整原文匹配译文，不会把同一精灵图下不同作者、不同内容的描述混用。
- 在本地 OPUS 初稿和用户授权的 Google 整段对照基础上，助手逐段阅读英文与现有中文，检查每句的含义，再改写为自然中文。本轮使用用户授权的并行审校，统一术语后合并；没有用自动复制未审内容的方式补齐覆盖数。
- 重点保留数字、否定、例外、因果、指代、幽默与作者语气。Wiki 用于核实专名、背景和典故，不用正篇设定覆盖社区作者的原创生态。
- 所有不同原文均有明确的整段修订记录。原有修订在 `Data/localization/zh-CN-dex-entry-overrides.json` 和 `zh-CN-dex-review-overrides.json`；本轮逐句成稿在 `Data/localization/dex-proofread/`，完整覆盖报告在 `zh-CN-dex-proofread-progress.json`。
- 这是一轮完整的助手逐句审校，不是人类译者签审。原文未说清的代词、拼写和社区自创名按保守措辞处理，并在参考记录中保留疑点；无法核实的名称不冒称官方译名。

### 语境与措辞修正示例

| 原文语境 | 修订处理 |
| --- | --- |
| 植物、发光器官、玻璃球中的 `bulb` | 分别判断种子、花苞、发光器官与灯泡，避免统一替词 |
| `train`、`charge`、`hood`、`staff` | 按上下文区分训练／列车、冲锋／充电、颈褶／兜帽、法杖／工作人员 |
| 每年蜕皮约 200 次 | 保留蜕皮过程，修正成脱毛的误译 |
| 曾被认为灭绝，后来由古生物学家发现 | 灭绝误传属于宝可梦，不修饰研究者 |
| 将其他宝可梦视为自己的 `court` | 按君王隐喻处理为王廷、臣属，避免译成法庭 |
| `doesn't seem to eat`、`unless they strike its tail` | 保留“似乎不进食”“除非先击中尾巴”，不扩写生理结论或弱化动作 |
| `Lucaslash` 等同名融合体 | 结合完整描述、融合编号与公开精灵图辨认，不只凭英文拼接名选中文 |
| 地名与形态名 | 核对夏干岛、叶之镇、米丽法城、利亚多村、毁坏的世界、呼拉呼拉风格等既有译名 |

## 分页和读取

图鉴按实际字体宽度分行，每页四行，支持三页及更多页面，翻页时保持同一条描述。页码位于正文之外。社区词库按文件版本缓存，避免每次打开或翻页时重新解析整个文件；上游词库更新后重建匹配。

## 来源与离线重建

原始社区资料及署名来自项目现有 `Data/pokedex/dex.json`。初稿采用 [OPUS 英译中模型](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh)，转换版来自 [gaudi/opus-mt-en-zh-ctranslate2](https://huggingface.co/gaudi/opus-mt-en-zh-ctranslate2)，许可为 Apache-2.0。随后按用户明确授权，仅将英文描述与临时术语标记发送给 Google 翻译作整段对照；作者、精灵图路径、存档与账号均未发送。

术语与背景参考项目中文包、[PokeAPI 名称表](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)、[游戏 Wiki 图鉴说明](https://infinitefusion.fandom.com/wiki/Pok%C3%A9dex)、[宝可梦百科](https://wiki.52poke.com/)、[Bulbapedia](https://bulbapedia.bulbagarden.net/)和 [FusionDex](https://fusiondex.org/) 的相关词条及精灵图。具体链接与判断依据集中记录于 `Data/localization/zh-CN-dex-reference-notes.json`，保留暂译名与原文歧义说明。

运行 `scripts/localization/build_proofread_dex.py` 可从版本内的修订记录离线重建最终中文图鉴，无需模型、网络或临时对照缓存。它先检查逐句覆盖，再原子写入译文文件。历史初稿和对照流程分别保留在 `translate_custom_dex.py` 与 `refine_custom_dex.py`；中文图片由 `build_chinese_images.py` 按已审查的文字区域重建。游戏运行仅需本地 JSON 和图片。
