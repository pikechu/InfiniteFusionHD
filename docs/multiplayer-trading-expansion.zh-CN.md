# 交易扩展：历史、提醒、邮件与合同

2026-10-23，特性分支 `codex/trading-center`。本扩展实现原方案后置的价格历史、收藏搜索、到货提醒、资产邮件、部分成交、拍卖、求购、代练、租赁与抵押借贷。原市场和面对面交换继续保留。入口为「交易中心 → 更多交易功能」；具体最终验收记录见文末。

## 成交历史和收藏搜索

- 历史仅统计实际完成的市场、拍卖和求购订单，不把挂牌价格当成成交价。可查看近30天按 UTC 日期汇总的开盘／收盘、最高／最低、成交数量、成交笔数及加权均价；均价按联机币整数向下取整。每次统计最新5000笔记录，超出时明确标记截断。
- 按精灵物种或道具 ID 区分，同时隔离不同玩法规则。窗口内互为买卖双方的账号对被剔除；这只是保守过滤，不把价格样本称为可靠估值。至少5笔、3个不同买家和3个不同卖家才标记样本充足。
- 每账号最多20个收藏搜索，可从当前市场筛选直接保存，也可重新编辑条件创建。保存完整筛选和排序；一口价市场出现匹配的新挂牌时生成站内到货提醒，同一收藏与挂牌只提醒一次。可以关闭提醒或删除收藏。
- 通知保存在服务器，离线后仍可查看；地图 HUD 显示自己的未读数，最多显示9999。支持单条和全部已读。拍卖被超价、合同结束和邮件退回也有通知；不发送邮件、短信或外部消息。

## 道具部分购买与资产邮件

道具市场可以选择购买数量。客户端确认的是所选数量及其总价，服务端同时核对挂牌版本。部分售出后只保留剩余数量的占用，搜索价格同步为剩余整单总价；上架费只在最初收取一次，撤单或到期只退回剩余部分。精灵仍按整只交易。旧客户端省略数量时购买当前整单。

资产邮件使用好友码指定另一注册账号，遵守对方的屏蔽设置。每封最多6只服务器精灵、8种可交易道具和一笔联机币；每小时最多发送20封。主题最长80字，正文500字。每个账号最多100封未处理的收／发邮件，未处理邮件优先展示，确保已接收的附件不会被近期历史挤出列表；超限发送整体拒绝，不占用资产。列表保留最近100封并优先列出全部待处理邮件。

发送后精灵仍归发送者并锁定，道具和联机币预留，不能在其他地方重复使用。收件人收取时才原子转移真实资产，生成普通待领取交付；重复收取不复制资产。收取前发送者可取消、收件人可拒收；30天未收取自动退回。已经收取不能召回，旧邮件回执也不能重新取得后来已转手的精灵。

## 共同合同规则

拍卖、求购、代练、租赁和借贷共用「我的合同」、稳定合同编号、条款版本和经济请求日志。操作前须查看当前条款；旧版本请求会要求刷新。每账号最多20个未结束合同，挂牌有效期1分钟至7天，客户端按小时填写。交易中心暂停新增交易时仍允许取消未接受合同、还款、归还和恢复已有结果。

发布费为基准金额的2%，向上取整，最低100、最高25000联机币，不因取消退费。基准金额分别是拍卖起拍价、求购总预算、代练报酬、一次租金、借贷本金。条款和费用发布后冻结。

资金、精灵与道具使用现有统一预留和锁。服务端按服务器时间处理到期，重启后继续；客户端退出不会取消已经达成的合同。收款时钱包满额的款项进入「更多交易功能 → 待收款」，可按钱包剩余容量领取，不丢款、不凭空扩充余额。

## 竞价拍卖与求购

拍卖可以是一只精灵或一组同种道具。发布者填写起拍总价、最低加价和期限；每次出价都核对当前版本。最高出价冻结联机币，被超价后释放原预留并收到提醒；同一人加价只调整自己的冻结额，不叠加占用。每次出价有持久审计记录。

最后60秒内的新最高出价把剩余时间延长到60秒，最多比原截止时间延后5分钟。有出价后卖家不能撤销。到期按最终最高价一次结算并生成交付；无人出价时退回原资产。查询、重启和重复通知不再次扣款或交付。

求购单预留全部预算，可购买指定道具或满足已发布属性条件的精灵。精灵条件支持物种、等级、性格、性别、特性、闪光、融合组成、IV 等现有筛选；服务端读取供货者实际资产核对，不接收供货者上传的属性声明。每次精灵供货一只，道具可以分次供货；数量和预算同步递减。发布者可取消剩余求购，到期也只释放未用预算。

## 代练与租赁

代练和租赁要求服务器当前启用原生玩法服务，停用时拒绝发布和接单，并保留已有撤单／归还处理。它们使用已准备完整数据、没有携带物且不在队伍中的精灵。接单后可以放入接单者的托管队伍，界面标出限时用途及归还时间；原训练师和资产身份保持。

代练发布者设定目标等级、可选 EV 最低目标、报酬、保证金及接单后1小时至7天的期限。目标必须高于当前至少一项属性。报酬在发布者钱包预留，接单者保证金另行预留。代练者使用自己的服务器道具或权威战斗培养；仅在服务器属性达到全部目标后验收并支付报酬。提前中止或超时未达标，报酬释放、保证金作为补偿支付给主人，精灵带着可信培养进度归还；到期时已经达标仍正常结算报酬。

代练精灵不能被转卖、投递交换池、发送邮件、释放、进化、融合、拆分、繁育或变更携带物，也不能降低 EV。租赁精灵仅允许队伍使用、原生战斗、回复和查看，不允许直接培养等其他变更。租赁期限1小时至30天，租金一次预付、提前归还不退，保证金归还时释放。

主动归还或到期时，服务端先取消涉及该精灵的未结算原生任务，再移除临时队伍引用，归还同一资产并生成给主人领取的交付。旧存档和迟到的工作进程结果都不能把它重新变成借用者的可用精灵。

## 抵押借贷

出借者预留本金，约定固定还款额、抵押精灵属性条件及1小时至30天期限。还款额范围为本金至本金的110%，不滚动计息。抵押条件只核对精灵实际属性，不提供自动估价，不能用市场价格筛选暗示抵押价值。

借款者查看条款和抵押精灵后明确接受；服务器锁定其精灵并发放本金。抵押期间精灵不能用于队伍、培养或其他交易。到期前按约定金额还款，原精灵退回借款者；到期未还，原精灵永久转给出借者。没有资产复制或「客户端声明已还款」入口。出借者不能在到期前强行没收抵押。

## 协议、迁移与运行

扩展接口位于 `/v1/market/history`、`/saved-searches`、`/notifications`、`/mail`、`/cash`、`/contracts` 下。历史、市场搜索和合同搜索是只读 POST，不占用经济操作日志。其余经济操作仍使用账号范围的 `request_id`；同 ID 不同参数被拒绝。

数据库版本为6。升级须停旧服务，使用 `trading_admin.py migrate --backup <新备份路径>`，先一致性备份再迁移。除新增扩展表外，会在事务中重建 `market_orders`，解除原来每个挂牌只允许一个订单的唯一约束，以支持部分成交；保留所有旧订单和请求回执。不能仅用旧版代码回滚新版数据库，回退须恢复配套旧库备份。

经济审计同时核对钱包／道具分录、待收款与对应分录、邮件预留、合同预算／保证金／抵押锁，以及临时使用权的当前持有者和期限。完整主线原生运行时仍需要 Windows；生产部署、公网和实体手机验收没有随本次扩展执行。
