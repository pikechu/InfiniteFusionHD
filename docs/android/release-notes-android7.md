# Android.7 本地测试发布说明

2026-10-21，`0.20.7-android.7` / versionCode 7，`org.kuray.kif`，KIF Android Test。普通 ARM64 与专用模拟器 APK 已构建并通过签名校验。仅本地测试签名，未上传测试渠道或公开发布。上一版记录保存在 [Android.6](release-notes-android6.md)。

## 变化

- 根据已确认示例实现半透明悬浮方向键、确认、返回。取消左右各 112 dp 的固定按钮栏，游戏保持 4:3 比例最大化显示。
- 其他快捷键、键盘和存档管理收进右上角「⋯」，保留需要时的组合操作。
- 「⋯ → 按键设置」新增 **65%–150%** 大小滑块、即时预览、保存、取消与恢复默认。保存到应用私有设置，独立于游戏存档。菜单入口保持固定尺寸，小屏会限制实际最大尺寸。
- Android 通过集中平台接口始终走全屏分支，不受 Windows 存档的窗口缩放档位影响；Windows 原缩放行为保留。不改写存档里的桌面画面设置。
- 多指按键按 pointer ID 跟踪；换向、取消、失焦、后台和菜单接管时释放按键。沿用原 JNI 输入桥和原游戏 UI。

使用说明及实现边界见 [虚拟按键](touch-controls.md)。

## 验证状态

Java 与 SDL 壳编译通过；全套主机检查通过，包括平台 62、输入 69、文本 188、选槽 35、真实本地 ZIP/文件事务 33 个断言，以及 444 个 Ruby 文件编译。这些不是设备游玩结果。

原 API30 AVD 已实际通过20个触控案例/197断言，以及游戏标题、选槽读档、65%/100%/150%、取消、默认、保存后杀进程重启保留、地图移动、队伍及满箱闪光浏览。实际Gboard输入r→隐藏→重开→z得到rz，虚拟确认并普通保存生成同名备份。真实SAF导出后第一次启动及读档仍保持960×720；一次Home热恢复正常。

存档仅更新E并新增rz备份，无删除；其他29份原文件保持SHA。导出ZIP的30个允许文件逐项匹配，最终冷读后31份清单与保存后完全相同。详细步骤和证据见[本版报告](android7-device-report.md)。

安装初次因空间不足失败，用户批准完整备份后尝试的12GiB副本扩容未成功，也未替换原环境。最后按用户授权，仅清理旧只读素材中4606份清单匹配文件，保留4份修改/新增记录及全部图片、缓存、下载和存档，实际释放753.77MiB；在原6GiB完成安装和回归。12GiB并非游戏最低容量，本轮也未改变新建模拟器的默认值，见[存储记录](avd-storage.md)。

## 范围与限制

本版不包含拖动布局、自定义透明度、单按钮独立缩放、全面触屏菜单或新版源码运行时接入。手机包未真机运行，未验证其他Android/屏幕/刘海组合、整体16KiB页或完整剧情通关。.7未全量重跑战斗/融合系列，不沿用历史结果冒充本版全量通过。.6的SAF首次缩放在本次API30往返未复现，其他系统仍需验证。

同包、同测试签名可以原地升级；卸载会删除应用私有数据，应先导出存档。APK约708MiB，完整解包素材仍约934MiB，且旧素材版本暂留供恢复；安装升级需要额外临时空间。本次受限清理属于QA维护，不代表应用已实现自动容量治理。
