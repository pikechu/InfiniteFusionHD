# Android.14 汉化与地图加载更新

版本：`0.20.8-android.14`，versionCode 14，ARM64，Android 11 及以上。沿用现有本地测试签名和固定的手机运行库；不是模拟器专用变体。

本次合并补齐开场与其他剧情、物品说明、设置及常规界面翻译，加入 111 张中文图片，修复中文换行与多页图鉴，并合入地图纹理复用和人物图层/动作缓存修复。

## 图鉴范围

- 保留最新 main 的 82,207 条英文社区记录。
- 本轮逐句审校范围为 15,005 条记录、14,423 种不同原文，原文、图片与作者均保留。
- 对完全相同的英文描述复用已审译文后，中文可覆盖 20,022 条记录。
- 其余 62,185 条暂保留英文，涉及 61,021 种待审原文。用户已确认本次先按这一范围发布，上传后继续新增图鉴汉化。

## 已完成验证

- 全部 82,207 条原生读取和三轮语言切换通过；20,022 条中文共 20,148 页的真实字体排版通过。
- 中文图片的尺寸、透明度、文字区域外像素和打包清单检查通过。
- 开场 576 条对白/选项、物品和设置、姓名控制符、分页、地图纹理缓存与人物图层回归通过。
- Android 主机测试、全部游戏 Ruby 与 Android 适配脚本的语法检查、异步网络队列和生产资源恢复器检查通过。详见 `docs/gameplay-evidence/2026-10-27-android14-integration/`。

APK 将从合并后的 main 完整构建，使用签名与资源摘要校验。成品散列值和 Google Drive 地址在构建、上传完成后另行记录。

尚未完成本版 Android 真机画面、帧率和触控手感验收；Windows 运行与主机测试不代表真机验收。
