# Android 显示模式

Android.8 在「⋯ → 显示模式」提供两个选项，点选后立即生效并自动保存：

- **保持比例（默认）**：游戏内容保持原有 512×384 / 4:3，完整放大到可用区域。宽屏左右会有余边。
- **拉伸填满**：游戏内容铺满可用区域，不裁切；宽屏中的人物和界面会横向变宽。

关闭设置不改变选择。杀进程后重启仍使用上次选择。选择独立保存在应用私有设置 `display/stretch_to_fill`，不写入 Ruby 存档，也不跟随存档 ZIP 导入导出。旧安装升级时若没有该设置，默认保持比例。

按键始终按屏幕安全区布局，显示模式不会移动或拉伸方向键、确认、返回和菜单，也不会改变已保存的按键大小。「⋯ → 按键设置」继续提供 65%–150% 的大小调整。刘海安全区保留；填满针对可用区域。

Java 在启动时同时配置 `mkxp.json/fixedAspectRatio` 和原生桥的保留状态，避免先出现另一种比例。运行中通过互斥保护的 `display_mode_poll` 将选择传给 Ruby，实际调用 mkxp 原有 `Graphics.fixed_aspect_ratio=`，仅在模式改变时重算视口。图形操作在游戏线程执行，Android View 的触摸坐标保持不变。清除按键状态、失焦和暂停均不会清除显示选择。

桌面平台不安装 Android 输入桥，保持原来的窗口缩放逻辑。没有改游戏分辨率、地图视野、剧情布局或素材。

实际 APK、设备、截图和验证范围见 [Android.8 设备报告](android8-device-report.md)。
