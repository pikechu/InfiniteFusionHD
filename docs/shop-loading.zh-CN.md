# 尼比市服装商店首次打开停顿

对应地图 382（PokéMart），事件 3 为服装柜台、事件 7 为帽子柜台。两者按 `pewter`、基础选项和已解锁地区生成商品列表，然后进入服装预览。该流程使用本地目录、JSON 与 PNG，没有素材下载调用。

## 已确认原因和修复

- `OutfitSelector.new` 原本无条件扫描服装、帽子和全部发型的十个版本。商品搜索中又会重复创建选择器，即使买衣服或帽子也多次探测无关的发型图片。改为仅在相应列表实际被请求时枚举，并保留换装、帽子和发型循环选择的入口。
- 每个商品查询原本重新读取三份服装 JSON 并重建对象。现在按源文件大小、修改/创建时间及当前存档的表对象复用；数据改变、表被替换或切换存档时重新加载。缓存存于进程类对象，不新增存档字段，格式错误仍然报告。
- 开店时仍保留原有约 0.6 秒镜头动画，以及首次读取本地预览 PNG 的耗时。此改动不移除动画、不修改价格、商品标签、库存、解锁或购买逻辑。
