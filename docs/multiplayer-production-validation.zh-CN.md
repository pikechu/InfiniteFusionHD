# 生产适配与部署材料本地验收

日期：2026-10-22。默认域名：`if.pikastairs.cc`。实现分支：`codex/overworld-chat`。

本阶段已实现生产适配和运维材料，没有连接服务器部署、修改公网 DNS、安全组或签发公网站点证书。

## 实现内容

- `production.py`：生产 WSGI 入口，保留原有协议与 Store 业务；要求可信本机代理提供客户端 IP，限制请求/并发，不记录密码、令牌或存档正文。
- `online.py`：有界 scrypt 计算移出数据库事务锁，注册竞争和计算期间凭据变更会重新检查；慢登录不阻塞其他业务请求。
- `production_data.py`：生产数据身份与完整表集校验，数据库缺失/错挂载时拒绝启动，生产连接使用 WAL/FULL。
- `production_ops.py`：显式新建/导入、在线一致性快照、加密备份、远程仓库回执、保留策略、校验、恢复与备份新鲜度检查。恢复保留当前副本、撤销旧会话/租约，并提高云存档修订号，防止旧客户端待上传队列覆盖恢复点。
- `release_manager.py` 与发布构建脚本：离线依赖、文件清单与哈希、路径/符号链接/损坏包拒绝、版本目录与代码链接切换。
- `deploy/`：默认域名的 Caddy、Gunicorn、systemd 服务与计时器、工具校验锁、显式 Linux 安装/准备/激活/回滚/恢复脚本。

实际命令与数据目录说明见 [生产运行手册](../server/multiplayer/deploy/README.md)。

本机集成链路为：真实 Caddy HTTPS → 生产 WSGI 适配器 → 真实 SQLite → 真实 Restic 加密仓库 → 恢复并重新登录。Windows 使用标准库测试宿主承载 WSGI，并非已经在 Windows 启动 Linux Gunicorn。测试的两个 HTTP 会话代表独立客户端，未把它表述为本轮重新运行过原生 Windows/Android 游戏画面。

完整用例执行时，Windows 目录符号链接权限不足，跳过了真正的原子代码链接切换用例；同一模块的发布验证、解包、损坏/穿越拒绝和幂等准备正常通过。没有为此改变全局 Windows 设置。Linux Gunicorn/systemd、主机重启和真实代码切换仍须在未来目标主机验收。

并发冒烟的耗时含 Windows 标准库客户端、TLS 连接和测试宿主开销，不是 Linux Gunicorn 或公网人数/延迟的容量认证。
