## 使用

打开游戏设置首页的 **Language**，选择 **简体中文**。游戏内修改后保存游戏，重启会恢复该存档的语言。标题页原有语言入口也可使用。英语、法语仍可切换。

游戏使用独立的 `Data/messages_zh.dat`；缺失、损坏或存档索引无效时回退英语。显示中文时使用已有的 Noto Sans SC 字体，切回英语会恢复玩家的字体设置。

## 适配方法

1. 宝可梦、招式、道具、特性、属性、训练家类型和奖章按内部 Symbol ID 对应到当前编号。匹配项没有编号偏移，KIF 独有数据不使用外部编号覆盖。
2. 剧情文本按当前地图及英文原文键匹配。控制符、参数不一致的 755 条源译文跳过，保留英文，避免丢失玩家名称、数字参数或消息控制功能。
3. 原汉化把菜单、战斗等文字直接写进脚本，语言文件本身没有 ScriptTexts 部分。导入工具用 Ruby Ripper 解析原脚本，并与已有 IF 英文参考及当前源码比对，只提取代码结构一致的静态字符串。220 个存在不同译法的键保守跳过，再由明确的界面译文补齐。
4. 宝可梦名称、种类和图鉴入口读取语言表，英文原始字段和游戏数据库不变。融合名称使用原汉化的中文名称片段，在显示时组合，切换语言不改写宝可梦、昵称或融合计算。
5. 融合界面的特性、招式和性格显示走现有本地化接口。Android 完整游戏打包也会带上独立中文包及来源说明。
6. KIF AI 对鬼火、电磁波、绝对零度的判断改用内部招式 ID，避免中文招式名影响判断。融合分类在显示时翻译，物种构造继续使用原始字段。

当前包含 15,379 条地图/公共事件译文，覆盖 710 组文本；另有 4,271 条脚本译文、532 个物种名称及中文融合名称片段。详细分类以生成报告为准。

2026-10-26 第二轮补译增加 556 条脚本文案，其中手工补充 355 条设置、说明与操作提示。七个 IF/KIF 设置页的可翻译标签、选项和说明已逐项检查；保留 S/M/L/XL、DNA、1v1/2v2/3v3、TCG、FGM、Tutor.net 和字体版本缩写。补充文本位于 Data/localization/zh-CN-settings.json。

对于整段方法发生无关变化的源脚本，导入器额外匹配同一方法内唯一且结构一致的语句；完整文件/方法的匹配结果优先，避免较弱匹配覆盖已有译文。参数或控制符有问题的人工补译会使构建失败。预设名使用参数插入，玩家自定义名称不翻译；融合选择提示也接入语言表。

本轮原生检查 18 项通过，包含七个设置页的文案清单、中英文切回及自定义预设名。最终运行 PID 18520 检查了游戏内选项。证据位于 temp/multiplayer/language-expanded-20261026/saves/，其中 settings-remaining.json 仅列出保留的尺寸、对战格式、功能专名及字体/样式缩写。

KIF 专有功能及无法安全匹配的条目继续显示英文；原汉化也有漏译。图片中的英文和融合自定义图鉴文本没有在本次重新汉化。语言切换不代表所有新增 KIF 文案都已翻译。
