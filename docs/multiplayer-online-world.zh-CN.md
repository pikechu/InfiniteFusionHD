# 在线模式、同地图玩家与聊天

特性分支 `codex/overworld-chat`。复用现有协议2服务，参考本地OpenMMO的认证后进入角色流程、会话登记及地图广播设计，独立实现本项目Ruby/Python接口，没有移植其Kotlin代码或协议。

## 使用

标题后的读档入口先选择在线或离线。在线必须注册/登录账号，也可继续使用尚未过期的凭据；身份校验和云存档拉取完成后才显示读档/新游戏。注册支持账号、密码及昵称。用户名忽略大小写，密码使用随机盐和scrypt保存，客户端不记录密码。登录凭据有效七天。

在线存档按服务器与账号分开保存于 `Multiplayer/OnlineSaves/<server-hash>/<identity>/`，离线继续使用原路径。返回标题可重新选择模式，在线游玩中不能直接切换账号/服务器或断开为离线。离线暂停菜单不显示联机入口。

主线地图自动同步坐标、朝向及预设角色外观编号。同地图、地图指纹和游戏兼容信息一致的玩家显示角色及昵称，移动做插值。远端角色使用独立渲染层，不进入本地事件或碰撞列表。移动约0.2秒同步、静止约0.8秒、隐藏时约2秒心跳；断线20秒清理。随机地图使用实际地图数据指纹，独立生成的不同地图不会仅因编号相同而混入。

暂停菜单选择“聊天”，或“联机 → 地图与世界聊天”。方向键翻阅，动作键切换频道，确认键输入，取消键返回；另有可点击按钮。地图频道仅当前同地图玩家可读，世界频道覆盖当前服务器，切图后过滤旧地图消息。按消息编号去重，支持中文和Unicode，每条最多200字、三秒最多三条。字符显示依赖安装字体，部分emoji可能缺字。服务保留最近七天、最多约10000条，客户端缓存200条。

主线事件、NPC、任务、战斗和物品仍使用各自存档。本功能未新增共享NPC、实时PVP或语音。

## 云存档

- 每60秒在安全地图空闲时自动保存；移动、对话或战斗结束后重试。手动保存先写本机恢复缓存，再上传；事件中保存延迟至事件结束。返回标题时补保存并等待上传，失败可重试或保留本地记录。
- 新角色自动选择空槽，避免覆盖已有角色。保留八个手动槽、两个自动槽；原保存界面仍可明确选择槽位。
- 每个账号仅一个游戏写入会话，租期120秒，心跳续期。另一个设备须退出原会话或等待租期到期。
- 每槽版本递增，上传使用固定upload_id，丢失回执重试原ID；上传中又保存会排队下一版本。重启先恢复未完成上传，再拉取云端。版本冲突保留本机记录并停止写入，不静默覆盖另一设备。
- 云端为受限JSON对象图及有界压缩/Base64数据，不从网络调用Marshal.load。恢复角色、精灵、背包、开关、变量及共享引用后，地图事件/解释器从本机安装资源重建，不恢复任意远端脚本调用栈。未知对象类型拒绝同步并保留本机缓存。
- 压缩上限1MiB、解压上限32MiB、云请求最多2MiB。Android旧HTTPS桥接的64KiB请求上限通过16KiB分片避开；分片按账号、会话、upload_id和校验和隔离，支持断点和唯一提交，五分钟清理未完成片段。

## Android

旧“Android没有联网模块”的结论对应早期APK。已核实 `main` 的Android.8及模拟器已安装版本有Java/JNI HTTPS模块、INTERNET权限和桥接库；当前工作区旧Android壳缺少这些启动入口。

本特性新增 `020_AndroidNetwork.rb`。Android HTTPS复用系统证书/主机名验证的Java桥接，拒绝不可信证书；联机JSON使用自有WireJSON，避免原生JSON整数转换。开发HTTP仅接受数字IP，使用安全Socket。Socket通过主线程Fiber和非阻塞IO轮询，避免当前模拟器在Ruby IO线程及原生域名/TLS路径上的崩溃。已有素材下载适配器可保留，联机独立传输支持大云存档及分片。

Java HTTPS桥接单次调用由原有20秒总期限控制，客户端在返回后检查更短的请求期限。同步JNI在慢公网HTTPS下可能造成短时画面停顿；数字IP非阻塞测试不构成所有HTTPS情况下的帧率保证。

旧壳补充桥接加载、native源码构建和打包缺项检查。更新已安装Android.8时，应使用最新Android壳与本特性合并后的构建，不能把当前旧壳版本号当成Android.8升级包。未在本轮重装/发布完整APK。

```powershell
& scripts/android/build_bridge.ps1
& '<Python>' scripts/multiplayer/build.py
# 按原安装文档，用真实Game重新导出租借目录
& '<Python>' scripts/android/build_apk.py
```

双方填写同一可达服务器。手机127.0.0.1指手机自身；模拟器可用10.0.2.2访问宿主机。公网使用可信HTTPS反向代理。凭据、profile和云存档数据库应私密保存。

局域网开发服务可用 `server/multiplayer/start-local.ps1 -BindAddress 0.0.0.0` 启动，两端在启动模式选择的“设置服务器”中填写 `http://电脑局域网IP:8765`。默认仅绑定127.0.0.1，适合同机测试。
